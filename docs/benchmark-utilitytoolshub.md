# Benchmark: utilitytoolshub.com vs UtilityHub

Reviewed 28 Oct 2026 from the public home page.

| Area | utilitytoolshub.com | UtilityHub (before) | UtilityHub (now) |
|---|---|---|---|
| Tool count | ~190 | 6 | 16 |
| Navigation | 7 category menus, theme toggle | flat list, inert category labels | category chips with counts, server + live search |
| Tool pages | one page per tool, short blurb | form + result only | form + how-to + FAQ + related tools |
| Structured data | not visible on home | home WebSite only | WebApplication + FAQPage on every tool |
| Processing | mostly in-browser | server round-trips | 10 new tools fully in-browser |
| Mobile app | Android app linked | none | none (gap) |
| Strongest areas | breadth: media, dev, design, health, finance, language | invoices, QR with Wi-Fi, accounts | same, plus common calculators/dev utilities |

## Biggest remaining gaps
1. Breadth: image/PDF/video/audio tools (high search volume) and more health/finance calculators.
2. Currency converter needs a live-rates API.
3. QR decoder, hash generator, timezone converter, regex tester, Markdown editor are commonly searched and cheap to add as browser-only tools.
4. No mobile app / PWA.
